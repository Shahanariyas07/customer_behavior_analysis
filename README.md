## 4. Project Workflow

1. **Data Loading:** Imported the dataset into Python using Pandas.
2. **Exploratory Data Analysis:** Explored data distributions, patterns, trends and relationships.
3. **Data Cleaning:** Handled missing values, duplicates, incorrect data types and inconsistencies.
4. **SQL Analysis:** Loaded cleaned data into MySQL and performed queries using filtering, joins, aggregations and other SQL operations.
5. **Dashboard Development:** Created an interactive Power BI dashboard to visualize key metrics and findings.
6. **Reporting:** Prepared a project report highlighting important insights and observations.
7. **Presentation:** Created a project presentation using Gamma.

## 7. How to Run

1. Clone this repository:
   ```bash
   git clone [Repository URL]
   ```
2. Install the required Python libraries:
   ```bash
   pip install pandas numpy matplotlib seaborn sqlalchemy pymysql
   ```
3. Open the Jupyter Notebook and run the Python analysis.
4. Import the cleaned dataset into MySQL.
5. Execute the SQL queries provided in the SQL folder.
6. Open the Power BI `.pbix` file to explore the dashboard.
